 🎬 Disney+ Clone

A responsive **Disney+ Hotstar-inspired streaming platform clone** built using **HTML, CSS, and JavaScript**. This project recreates the look and feel of a modern OTT streaming platform with a responsive interface, movie/show browsing sections, banners, and interactive UI elements.

 📌 Project Overview

The **Disney+ Clone** is a frontend web development project created to practice and demonstrate skills in:

* HTML5
* CSS3
* JavaScript
* Responsive Web Design
* DOM Manipulation
* UI/UX Design
* Frontend Development

The project provides a streaming-platform-style interface where users can browse different categories of movies and shows through a visually appealing layout.

 ✨ Features

* 🎬 Modern streaming-platform interface
* 🏠 Home page with featured content
* 🖼️ Hero/banner section
* 🎞️ Movie and TV show cards
* 📂 Multiple content categories
* 🔍 Search interface
* 📱 Responsive design for different screen sizes
* 🎨 Disney+ Hotstar-inspired UI
* ⚡ Interactive elements using JavaScript
* 🧭 Navigation bar
* ▶️ Content-focused browsing experience

 🛠️ Technologies Used

 🚀 Getting Started

 1. Clone the repository


git clone https://github.com/Harshkumar1601/Disney-clone.git


 2. Navigate to the project directory


cd Disney-clone


 3. Run the project

Since this is a frontend project, you can open `index.html` directly in your browser.

Alternatively, if you are using **VS Code**, install the **Live Server** extension and open the project using Live Server.

 💻 How to Use

1. Open the website.
2. Browse through the available content sections.
3. Explore different movie and show categories.
4. Use the navigation and interactive elements.
5. Resize the browser window to see the responsive design.
